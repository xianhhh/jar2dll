# Security policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability in the native
loader, JAR parser, memory mapper, or packaged artifacts. Contact the repository
maintainer privately through the security contact configured on GitHub and include:

- affected version or commit;
- minimal reproduction steps;
- impact assessment; and
- any proposed mitigation.

Reports will be acknowledged when a maintainer is available. Do not include
working malware or sensitive credentials in the report.
